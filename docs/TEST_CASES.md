## How the tests stay reliable

- They run against a separate test database (`test_db.sqlite3`, `test_reports.sqlite3`), flushed between tests; the shop's `db.sqlite3` is never opened.
- Each test creates its own data with `tests/factories.py`, so any test can run alone (`pytest -k <name>`) or in any order (`.\run_tests.ps1 -Random`).
- Locators are roles, labels, visible text and `data-testid` only; waiting is done by Playwright's `expect`, never by fixed sleeps.
- Each browser test checks what the user sees and what was stored in the database.
- A failed test saves a screenshot to `reports/screenshots/<run>/`, embedded in that run's HTML report.
